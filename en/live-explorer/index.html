What can you explore in Kayhan?

Interactive 3D Solar System

Explore the Sun, eight planets and selected moons in a navigable 3D scene. Select an object to open its information.

Calculated planetary positions

The planet-position panel uses the current date and time on your device. Available calculations depend on which astronomy engine has loaded.

Earth's day and night

See an approximate day/night boundary and learn how Earth's rotation and sunlight create the changing view.

Space missions

Learn about missions such as Voyager, Juno, Parker Solar Probe and Europa Clipper, and locate their destinations in the 3D scene.

Learn and test your knowledge

Use short astronomy questions and the topic guides to learn more about planets, moons and exploration.

Your local time

Clock displays use the visitor's device time zone, so local clock values can differ between visitors in different regions.

What does “live” mean in this space explorer?

Some calculations run in the visitor's browser and use the current device time. As time advances, calculated positions can be refreshed. When the Astronomy Engine library is available, the explorer uses it for astronomical calculations; otherwise, it falls back to a simpler orbital model.

This is an interactive educational simulation, not a live telescope broadcast, spacecraft camera or continuous satellite video. Distances and sizes in the 3D scene are compressed so that objects can be seen together; they are not a fully scaled physical map. Mission paths shown in the interface are conceptual illustrations, not live spacecraft telemetry or navigation trajectories.

For clarity: “current position” means a position calculated for the selected time. It does not mean that Kayhan is receiving continuous live feeds from every telescope or satellite.

How to explore space with Kayhan

  1. Choose “Launch the 3D space explorer” to open the main experience.
  2. Select a planet or celestial object in the scene or object list to read its profile.
  3. Use the orbit, label and moon controls to change the Solar System view.
  4. Open the Kayhan Science Center to explore planetary positions, Earth, missions and the learning quiz.

Frequently asked questions about online space exploration

Can I watch the universe live?

You can open an interactive Solar System simulation and inspect calculated planetary positions. This page does not provide a live video of the universe or a telescope feed.

Do the planets move in the 3D explorer?

The scene represents orbital motion using time and orbital models. For readability, displayed scale and animation speed may differ from real distances and motion.

Are planetary positions the same for every visitor?

A calculated position corresponds to a particular instant, while local clock displays follow each visitor's device time zone. The simplified fallback model may be less accurate than a specialist ephemeris.

Are Earth's night lights a live satellite image?

No. The night-light layer may use a static satellite composite. It is not a live video or a real-time map of city lights.

Do I need to install an app?

No installation is required. Kayhan runs in a web browser. A modern browser and a suitable screen make the experience easier to use.
